# 영어 연습장

휴대폰 홈 화면에 설치해서 쓰는 영어 연습 웹앱입니다.

- 사이트: https://easidyl-coder.github.io/english-app/
- 설치: 휴대폰 브라우저로 위 주소를 열고 → 공유(또는 메뉴) → **홈 화면에 추가**

## 기능
- **오늘의 레슨** — Day 1부터 문법 순서대로 (문법 카드 · 문장 8개 · 단어 · 연습)
- **문장 조립** — 레슨 문장 / 전체 문장
- **단어** — 3단계 암기 (외우는 중 → 외운 → 외외운), 빈칸 퀴즈
- **듣기·말하기** — 뜻을 보고 소리 내어 말한 뒤 원어민 발음과 비교
- **막혔던 말 메모** — 영어로 말이 막혔던 순간을 적어두고 나중에 채우기
- **구글 로그인** — 여러 기기에서 진도 이어서

## 파일
| 파일 | 하는 일 |
|---|---|
| index.html | 앱 전체 화면·기능·데이터 |
| ipa.js | 단어 발음기호 |
| sw.js | 오프라인에서도 열리게 해 주는 캐시 |
| sync.js · firebase-config.js | 로그인과 진도 동기화 |
| manifest.webmanifest · icon-*.png | 홈 화면 설치용 |
