# 서인의 영어 연습장

휴대폰에 '앱 설치'해서 쓰는 영어 연습 웹앱이에요. 10~20명이 각자 구글 로그인으로 자기 진도를 저장할 수 있게 만들고 있어요.

## 파일 설명

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 전체 화면·기능·단어 933개·문장 232개 |
| `manifest.webmanifest` | 휴대폰에 '앱 설치'할 때 쓰는 이름·아이콘·색 정보 |
| `icons/` | 앱 아이콘 (192, 512, 안드로이드용 둥근 아이콘) |
| `sw.js` | 인터넷이 끊겨도 앱이 열리게 해 주는 파일 |
| `firebase-config.js` | 로그인·진도 저장 서버 설정값 (지금은 비어 있음 → 기기에만 저장) |
| `sync.js` | 로그인하면 진도를 서버와 맞춰 주는 파일 |

## 진행 단계

1. [완료] 지금 앱을 이 폴더로 옮기기
2. [완료] 앱 설치(아이콘·오프라인) 기능 넣기
3. [완료] 로그인·진도 저장 코드 넣기 (설정값만 넣으면 켜짐)
4. [할 일] GitHub Pages에 올려서 휴대폰 주소 만들기 — 서인님 계정 필요
5. [할 일] Firebase 프로젝트 만들고 설정값 넣기 — 서인님 계정 필요
6. [할 일] 매일 단어·문장 추가 방식을 이 폴더(GitHub) 기준으로 바꾸기
