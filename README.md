# 톡톡 잉글리시

휴대폰 홈 화면에 설치해서 쓰는 여행 영어 연습 웹앱입니다.

- 사이트: https://easidyl-coder.github.io/english-app/
- 설치: 휴대폰 브라우저로 위 주소를 열고 → 공유(또는 메뉴) → **홈 화면에 추가**
- 개인정보 처리방침: [privacy.html](https://easidyl-coder.github.io/english-app/privacy.html)

## 기능
- **오늘의 레슨** — Day 1~80, 문법 순서대로 (문법 카드 · 구어체 문장 8개 · 단어 · 시험). 10일마다 단원 시험
- **실전 회화** — 공항·카페·식당·숙소·택시·쇼핑·길 찾기·환전 등 상황별 문장
- **문장 조립** — 뜻을 보고 단어 조각을 순서대로. 틀린 문장은 맞힐 때까지 다시 나옴
- **단어** — 약 5,100개(레벨 1~10), 예문 빈칸 퀴즈, 잊을 때쯤 다시 나오는 3단계 복습
- **듣기·말하기** — 음성 인식으로 말하기 채점 (안 되는 기기는 스스로 확인)
- **레벨 테스트** — 약 3분, 내 레벨에 맞는 단어·문장·레슨부터
- **XP · 배지 · 연속 공부일** — 한 주에 하루는 쉬어도 연속이 이어짐
- **주간 리그** — 로그인 후 직접 참여, 별명과 이번 주 XP만 공개
- **막혔던 말 메모** — 영어로 말이 막혔던 순간을 적어 두고 나중에 채우기
- **구글 로그인(선택)** — 여러 기기에서 기록 이어 가기, 나 탭에서 계정 삭제
- 오프라인에서도 열림 · 어두운 화면 지원

## 파일
| 파일 | 하는 일 |
|---|---|
| index.html | 앱 전체 화면·기능·데이터 |
| ipa.js | 단어 발음기호 |
| sw.js | 오프라인에서도 열리게 해 주는 캐시 |
| sync.js · firebase-config.js | 로그인, 기록 동기화, 주간 리그, 계정 삭제 |
| firestore.rules | Firestore 보안 규칙 (Firebase 콘솔에 붙여 넣어 적용) |
| privacy.html | 개인정보 처리방침 |
| manifest.webmanifest · icon-*.png | 홈 화면 설치용 |

## Firebase 보안 규칙 적용하기
1. [Firebase 콘솔](https://console.firebase.google.com/) → 이 프로젝트 → **Firestore Database** → **규칙** 탭
2. 이 저장소의 `firestore.rules` 내용을 통째로 복사해 붙여 넣기
3. **게시** 누르기
